A presoft weboldalakat és egyedi szoftvereket készít kis- és középvállalkozásoknak. Minden munka előzetes látványtervvel indul, az ügyfél arculatára épül, és fix áron készül el. Az elkészült forráskód az ügyfélé.

## Mivel foglalkozunk

| Terület | Mit jelent |
| --- | --- |
| **Weboldalak** | Egyoldalas és többoldalas céges weboldalak: gyorsak, mobilbarátok, keresőoptimalizáltak. |
| **Webalkalmazások** | Ügyfélportálok, ajánlatkészítők, foglalási és belső rendszerek, amelyek böngészőből, telepítés nélkül használhatók. |
| **Dashboardok** | Vezetői riportok és mutatószámok egy képernyőn, automatikusan frissülő adatokkal. |
| **Tartalomkezelés (CMS)** | Egyszerű admin felület, amelyen a szövegek, képek és termékek fejlesztő nélkül frissíthetők. |
| **Mobilalkalmazások** | iOS és Android appok ügyfeleknek és terepen dolgozó csapatoknak. |
| **Modernizálás és integráció** | Elavult weboldalak és régi rendszerek újraépítése, összekötés számlázóval, webshoppal, CRM-mel. |

## Hogyan dolgozunk

- **Látványterv előre** – a megrendelő a munka kezdete előtt látja, mit kap.
- **Fix ár** – az ajánlatban szereplő összeg nem változik menet közben.
- **A forráskód az ügyfélé** – nincs bezártság, a kód átadásra kerül.
- **Kipróbálható minták** – minden szolgáltatáshoz működő minta tartozik a weboldalon.

## Nyílt forráskódú munkáink
